Название и суть проекта: Автотесты для проверки UI-функциональности сервиса Stellar Burgers(регистрация, вход по разным точкам, переходы в личный кабинет и конструктор, выход из аккаунта)
Список файлов: conftest.py - фикстуры, locators.py - локаторы, data.py - тестовые данные и генераторы, папка tests - с тестами
Инструкция по установке:
установка библиотек из списка: pip freeze requirements.txt
Команда запуска всех тестов: pytest -v
